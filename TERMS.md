# Terms of use

TraceProof is a local QA demonstration distributed under the MIT license. Its browser replay is a lightweight DOM runner, not an isolated production browser worker. Run receipts are helpful engineering evidence but are not trusted compliance records.

Only test systems and data you are authorized to use. Review generated Playwright code before using it in CI or against another environment. Demo identities and records are fictional. The included authentication is for portfolio demonstration. Public production use additionally requires secrets management, MFA/SSO, tenant isolation, isolated browser execution, retention controls, encrypted backups, monitoring, and incident response.
